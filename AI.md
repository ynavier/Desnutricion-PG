Actúa como un arquitecto de software senior, diseñador UX/UI especializado en plataformas clínicas y experto en sistemas de salud digital orientados a vigilancia nutricional infantil, Big Data y Machine Learning.

Necesito diseñar una aplicación web moderna, profesional e inteligente enfocada en la predicción y clasificación de la desnutrición infantil en niños menores de 5 años mediante técnicas de Machine Learning.

========================
OBJETIVO GENERAL DEL SISTEMA
========================

El sistema debe permitir:
- Analizar datos históricos relacionados con desnutrición infantil.
- Generar predicciones y clasificaciones usando Machine Learning.
- Detectar riesgos nutricionales tempranos.
- Facilitar el seguimiento clínico infantil.
- Generar alertas preventivas.
- Mostrar dashboards interactivos.
- Mejorar la toma de decisiones clínicas y administrativas.
- Fortalecer procesos de salud pública y vigilancia nutricional.

El sistema NO debe diagnosticar enfermedades, sino apoyar la toma de decisiones preventivas mediante análisis predictivo.

========================
ENFOQUE VISUAL Y FUNCIONAL
========================

La plataforma debe priorizar VISUAL y FUNCIONALMENTE el enfoque clínico y sanitario por encima del enfoque de inteligencia artificial.

La IA debe sentirse como:
- apoyo clínico,
- recomendación inteligente,
- sistema preventivo,
- herramienta secundaria integrada.

NO debe sentirse como:
- una plataforma futurista exagerada,
- un sistema centrado únicamente en IA,
- una interfaz cyberpunk o tecnológica extrema.

La interfaz debe transmitir:
- Confianza clínica
- Profesionalismo médico
- Salud pública
- Atención infantil
- Seguridad
- Claridad visual
- Monitoreo preventivo
- Estabilidad institucional

Debe verse como:
- una plataforma hospitalaria moderna,
- un sistema epidemiológico profesional,
- un dashboard clínico institucional,
- una solución SaaS médica real.

========================
ROLES DEL SISTEMA
========================

La plataforma contará con únicamente 2 roles:

1. ANL (Analítica)
2. CLI (Clínica)

-----------------------------------
ROL ANL (Analítica)
-----------------------------------

Corresponde al personal administrativo y analítico encargado de:
- análisis de datos,
- dashboards,
- modelos predictivos,
- reportes,
- vigilancia epidemiológica,
- gestión de usuarios.

Funciones:
- Acceso completo al sistema.
- Visualización de dashboards avanzados.
- Entrenamiento de modelos de Machine Learning.
- Comparación de modelos predictivos.
- Generación automática de reportes.
- Gestión de datasets.
- Carga de archivos CSV/Excel.
- Configuración de variables predictivas.
- Visualización de métricas:
  - Accuracy
  - Recall
  - Precision
  - F1 Score
  - Matriz de confusión
- Gestión de usuarios.
- Registrar nuevos usuarios CLI.
- Habilitar/Inhabilitar usuarios CLI.
- Configuración de alertas.
- Gestión de indicadores clínicos.
- Acceso a análisis históricos.
- Proyecciones futuras.

El usuario ANL es el ÚNICO autorizado para registrar usuarios dentro del sistema.

-----------------------------------
ROL CLI (Clínica)
-----------------------------------

Corresponde al personal médico y de enfermería encargado de:
- atención clínica,
- seguimiento nutricional,
- monitoreo infantil,
- registro de controles,
- consulta de alertas preventivas.

Funciones:
- Registrar pacientes.
- Consultar información clínica.
- Ver predicciones nutricionales.
- Consultar alertas generadas por IA.
- Actualizar seguimiento nutricional.
- Registrar controles antropométricos.
- Consultar historial del paciente.
- Ver recomendaciones preventivas.
- Visualizar gráficos básicos del paciente.

Restricciones:
- NO puede registrar usuarios.
- NO puede entrenar modelos.
- NO puede acceder a configuraciones administrativas.
- NO puede modificar datasets históricos.
